# Step 37 failure-case evidence

This directory contains the machine-readable failure-case manifest used by `STEP37_FAILURE_CASES.md`.

- `failure_cases.json` — five measured failure cases, their pipeline loss points, mitigation status, and source evidence.
- `local_verification.json` — generated by `python scripts/verify_step37_failure_cases.py`; cross-checks the Step 37 claims against the frozen Step 34, Step 34A, Step 34D, and Step 36 evidence.
- `test_summary.json` — focused pytest result for the Step 37 verifier contract.

The manifest intentionally records that detector v2 has no additional unseen-property evaluation set. The Step 34 Mozart house result remains the held-out evaluation for the original detector configuration.
