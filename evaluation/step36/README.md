# Step 36 evaluation artifacts

- `policy.json` — current frozen-policy candidate and SHA-256 fingerprint.
- `candidate_review.template.csv` — owner-review columns used after extracting ambiguous Step-35 proposals.
- `local_verification.json` — local test evidence. It intentionally does not contain fabricated development or challenge accuracy.

Real development and challenge outputs are generated by `scripts.measure_step36_agentic` and should be preserved as separate run directories rather than copied into this folder without their media/run context.
